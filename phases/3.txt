# MM Electricals — Phase 3

## Purchases, Sales, Customers, Vendors, Payments & Credit

The MM Electricals Phase 1 and Phase 2 systems are implemented.

Inspect the existing code before changing anything.

Do NOT rewrite working architecture.

This phase is:

**PHASE 3 — TRANSACTION MANAGEMENT**

---

# 2. PURCHASE TRANSACTION SAFETY

A purchase must be atomic.

The complete transaction must:

1. Validate vendor
2. Validate products
3. Validate quantities
4. Validate prices
5. Create purchase
6. Create purchase items
7. Create batches
8. Increase stock
9. Create stock movements
10. Record payment if applicable
11. Update vendor balance
12. Commit

If any step fails:

ROLLBACK EVERYTHING.

---

# 3. PREVIOUS BATCH WORKFLOW

During purchase entry for an existing product:

Show previous batch information.

Provide:

* Use previous pricing
* Copy previous pricing and edit
* Set new pricing

Show cost change warning.

Do not silently modify old batch pricing.

# 4. SALES / BILLING

Build a fast sales workflow.

The owner should be able to:

1. Search product
2. Select product
3. Add quantity
4. Apply discount
5. See price/margin warning
6. Select customer
7. Select payment method
8. Complete sale

Support:

* cash
* UPI
* card
* bank transfer
* credit
* partial payment

---

# 5. SAFE PRICE WARNING

During sale, if the final selling price falls below the batch's configured safe selling price:

Show:

"Below Safe Selling Price"

Display:

* batch cost
* configured selling price
* safe selling price
* requested discount
* resulting price
* margin

Allow owner override.

Do not hard-block unless a future setting explicitly enables hard enforcement.

Record overrides in the audit log.
